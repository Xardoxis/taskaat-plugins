# Taskaat Claude Code Plugins Marketplace

Official marketplace for [Taskaat](https://taskaat.dev) plugins in Claude Code.

## Adding the Marketplace

In Claude Code, run:

```bash
/plugin marketplace add Xardoxis/taskaat-plugins
```

## Available Plugins

| Plugin | Description | Install Command |
|---|---|---|
| **taskaat** | AI-native task management, execution flows, and project memory | `/plugin install taskaat@taskaat` |

## Updating Plugins

To update plugins from this marketplace to the latest version:

```bash
/plugin update taskaat
```
